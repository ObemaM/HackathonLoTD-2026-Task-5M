# План разработки

## Этап 1 — сквозной baseline

- сборка ROS-пакета;
- приём обоих вариантов входного topic;
- удаление нулевого заполнения;
- ручная калибровка коридора;
- debug clouds и RViz markers;
- измерение processing time.

Критерий готовности: bag проигрывается на 10 Гц, узел публикует результат для каждого
кадра и визуально показывает кандидатов.

## Этап 2 — геометрия пути

- выделить кандидаты рельсов по высоте/intensity;
- искать пару рельсов в последовательных поперечных срезах;
- отбрасывать невозможную ширину и резкие скачки;
- построить spline центральной линии;
- заменить прямой ROI на коридор вдоль spline.

Критерий готовности: повороты и стрелки не превращают стену в препятствие.

## Этап 3 — синтетика и метрики

- добавлять коробки, человека, трубу и кабель;
- учитывать падение плотности с расстоянием;
- генерировать объекты внутри и снаружи габарита;
- считать recall, false positives/min, distance error и p95 latency.

## Этап 4 — устойчивость

- разные типы тоннеля;
- платформа;
- гермозатвор;
- стрелка;
- временное подтверждение 2 из 3 кадров;
- тестирование на полностью отложенном bag.

## Этап 5 — сдача

- Docker build с чистого состояния;
- запуск без сети;
- README и схема архитектуры;
- таблица экспериментов;
- видео и репетиция демонстрации.
