# Эксперименты

`scenarios.yaml` — начальный перечень тестов, а не готовая разметка. После появления
генератора синтетики каждый сценарий должен иметь воспроизводимый seed и ожидаемый ответ.

Результаты складываются в `experiments/results/` и не коммитятся автоматически. В
презентацию переносится агрегированная таблица:

- recall по диапазонам расстояния;
- false positives в минуту на чистых bags;
- ошибка расстояния;
- processing time p50/p95/p99;
- процент кадров, где успешно построен путь.
